# 네이버 블로그 자동 포스팅

AI로 글 초안을 만들고(선택), 브라우저 자동화(Playwright)로 내 네이버 블로그에 **임시저장 또는 발행**까지 하는 도구입니다.

> 네이버의 공식 "블로그 글쓰기 API"는 종료되어서, 사람이 글을 쓰는 것처럼 브라우저를 대신 조작하는 방식을 씁니다.
> **반드시 내 PC에서 실행하세요.** 클라우드 서버에서 로그인하면 네이버 보안에 막힙니다.

## 1. 설치 (최초 1회)

Python 3.10 이상이 필요합니다.

```bash
cd naver-blog-auto
pip install -r requirements.txt
python -m playwright install chromium
```

`.env.example` 파일을 복사해서 `.env` 파일을 만들고 내용을 채웁니다.

```
NAVER_BLOG_ID=내블로그아이디        # blog.naver.com/여기부분
ANTHROPIC_API_KEY=sk-ant-...      # AI 글 생성할 때만 필요
SIGNATURE=읽어주셔서 고마워요!      # 글 끝 인사말 (선택)
```

## 2. 로그인 (최초 1회)

```bash
python login.py
```

브라우저 창이 뜨면 **직접** 로그인하고(로그인 상태 유지 체크), 터미널에서 Enter를 누릅니다.
아이디·비밀번호는 어디에도 저장되지 않고, 로그인 세션만 `.naver-profile/` 폴더에 남습니다.
로그인이 풀리면 이 단계만 다시 하면 됩니다.

## 3. 글 준비

`posts/` 폴더에 `.md` 파일을 넣습니다. (예시: `posts/20261025-sample.md`)

```markdown
---
title: 글 제목
tags: 태그1, 태그2, 태그3
---
## 소제목
본문 문단입니다. 빈 줄은 한 줄 띄우기가 됩니다.

![](images/사진.jpg)
```

- `## 소제목`은 굵은 ▍소제목, `**굵게**`·`__밑줄__`은 실제 서식으로 바뀝니다.
- `![](images/사진.jpg)` 위치에 사진이 업로드됩니다. 사진은 `images/` 폴더에 넣으세요.

**AI로 맛집·축제 후기 만들기 (선택)**

내가 다녀온 곳의 **메모와 사진**을 주면, AI가 정해진 구성으로 글을 써 줍니다.

1. `visits/` 아래에 가게(또는 축제) 이름으로 폴더를 만듭니다. 예: `visits/OO청국장/`
2. `templates/food_memo.txt` (축제는 `festival_memo.txt`)를 그 폴더에 `memo.txt`로 복사해서 채웁니다.
   **맛·느낌은 짧게라도 내 말로** 적어 주세요. 그래야 내 글이 됩니다.
3. 내가 찍은 사진을 같은 폴더에 넣습니다. 파일 이름 순서대로 전달되니 `01_외관.jpg`, `02_내부.jpg`처럼 번호를 붙이면 좋아요. (아이폰 HEIC는 JPG로 바꿔서)
4. (선택) 참고하고 싶은 블로그 글의 **본문 글자만** 복사해서 `reference.txt`로 저장합니다.
5. 실행:
   ```bash
   python generate.py food visits/OO청국장
   python generate.py festival visits/OO축제
   ```

맛집 글의 구성·사진 배치·강조·태그 규칙은 [`references/food_style_guide.md`](references/food_style_guide.md)에 있고, AI에게 자동으로 전달됩니다. 가이드를 고치면 글 스타일도 바뀝니다.

맛집 글 구성: 도입 → **한눈에 보기**(주소·영업시간·주차·가격 요약) → 찾아가는 길과 주차 → 매장 분위기 → 메뉴와 가격 → 직접 먹어본 후기 → **솔직한 총평**(아쉬운 점, 추천 대상) → 태그 12~15개

**참고 글이 있을 때 겹치지 않게 하는 장치**
- AI에게 참고 글의 **구성과 말투만** 참고하고, 문장이나 사실은 가져오지 말라고 지시합니다.
- 글이 완성되면 **유사도 검사**를 자동으로 돌려, 참고 글과 겹치는 비율과 많이 겹치는 문장을 보여 줍니다. 겹침 15% 미만이 목표입니다.
- 직접 고친 뒤 다시 검사하려면: `python check_similarity.py posts/내글.md visits/OO청국장/reference.txt`
- `reference.txt`는 저장소에 올라가지 않습니다(.gitignore).

> 다른 사람의 **사진은 절대 쓰지 마세요**(저작권 침해). 가 보지 않은 곳을 다녀온 것처럼 쓰는 것도 안 됩니다. 네이버 유사문서·저품질 판정은 물론 법적 문제(허위 후기)가 될 수 있습니다.

**자유 주제 글**: `python generate.py topic "가을 단풍 명소 추천" --keywords "단풍명소, 가을여행"`

`--dry-run`을 붙이면 API를 쓰지 않고 어떤 메모·사진이 들어가는지만 확인합니다.
초안은 `posts/`에 저장됩니다. **올리기 전에 꼭 직접 읽고 고치세요.**

**글 파일에서 쓸 수 있는 서식**: `## 소제목` → 굵은 ▍소제목, `**굵게**`, `__밑줄__`, `---` → 문단 띄우기, `![](경로)` → 사진.
`.env`의 `SIGNATURE`에 인사말을 적으면 모든 글 끝에 자동으로 붙습니다.

## 4. 올리기

```bash
# 임시저장 (기본값, 추천) → 블로그에서 확인 후 직접 발행
python post.py posts/20261025-sample.md

# 바로 발행
python post.py posts/20261025-sample.md --publish

# posts/ 에서 파일 이름순으로 가장 앞의 글 1개를 발행하고 posts/done/ 으로 옮기기
python post.py --next --publish
```

실패하면 `error.png`에 그때 화면이 저장됩니다.

## 5. 매일 자동으로 올리기

`posts/`에 글을 여러 개 쌓아두면 하루에 1개씩 발행합니다. `--jitter 30` 옵션을 주면 매번 0~30분 사이 랜덤한 시간에 올라갑니다.

**Windows (작업 스케줄러)**
1. `작업 스케줄러` → `기본 작업 만들기`
2. 트리거: 매일, 원하는 시간
3. 동작: 프로그램 시작 → `naver-blog-auto\run_daily.bat` 선택
4. 결과는 `post.log`에 남습니다.

**Mac / Linux (cron)** — `crontab -e`에 추가:
```
0 9 * * * cd /경로/naver-blog-auto && python3 post.py --next --publish --jitter 30 >> post.log 2>&1
```

PC가 켜져 있고 로그인된 상태여야 동작합니다.

- 처음에는 **임시저장 모드로 몇 번 확인**한 뒤 `--publish`로 바꾸세요.
- 남의 글 복사나 과장 광고는 쓰지 마세요. 네이버 운영정책 위반이 될 수 있습니다.
- 네이버가 에디터 화면을 바꾸면 버튼 위치를 못 찾을 수 있습니다. 그럴 때는 `post.py`의 선택자(`.se-...`, `publish_btn` 등)를 고쳐야 합니다. `error.png`를 같이 보내주시면 수정해 드릴게요.
