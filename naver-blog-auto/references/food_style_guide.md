# 맛집 후기 스타일 가이드

반응이 좋았던 네이버 맛집 후기 한 편(공감 29, 댓글 5)을 분석해서 **구성, 사진 배치, 강조 방식, 태그 패턴**만 정리한 가이드입니다.
원문의 문장이나 사진은 들어 있지 않습니다. 내용은 항상 **내가 직접 다녀온 메모와 사진**으로 채웁니다.

`generate.py food` 를 실행하면 이 파일이 자동으로 AI에게 전달됩니다. 직접 글을 쓸 때 참고해도 됩니다.

---

## 1. 레퍼런스 글 분석

### 전체 흐름
| 순서 | 구간 | 들어간 것 | 사진 |
|---|---|---|---|
| 1 | 도입 | 가게 공식 SNS 링크 카드 → 이 지역에서 이 메뉴가 유명한 이유 → 방문 계기(여행 동선상 가까워서) | 링크 카드 |
| 2 | 소제목: 위치·주차 | 역/시장 등 랜드마크 기준 위치, 기차·자차 각각 오는 법, 주변 연계 코스, 주차장 위치 | 외관 4장 (2×2) |
| 3 | 소제목: 내부·메뉴 | 분위기 한 줄 평, 들어설 때 첫 감각(냄새 등), 붐비는 시간 피하는 팁 + 우리가 간 시간 | 내부 2장 → 안내문 2장 → 메뉴판 1장 |
| 4 | 메뉴 소개 | 대표 메뉴 → 곁들임 메뉴 나열 → 지역 특산물 메뉴 강조 → 우리가 고른 조합과 이유 | (메뉴판 사진 아래) |
| 5 | 소제목: 음식·반찬 | 상차림 전체 → 반찬 구성 → 메뉴별 후기 (사진 → 설명 순서) | 전체샷 → 반찬 2장 → 메뉴별 1~2장 |
| 6 | 마무리 | 이 집의 장점 한 문단 요약 → "○○ 생각나면 다녀와 보세요" 권유 | – |
| 7 | 끝 인사 | "공감·댓글 부탁" 스티커 | 이미지 |
| 8 | 태그 | 15개 | – |

### 잘된 점 (따라 할 것)
- **사진 먼저, 글은 뒤에.** 모든 구간이 사진 묶음 → 설명 2~4문단 순서로 반복됩니다.
- **문단이 아주 짧습니다.** 한 문단에 1~3문장, 모바일 화면 기준 2~3줄이면 끝납니다.
- **동행자 시점이 계속 나옵니다.** "아이도 좋아해서 주문", "아이는 매워서 덜 먹고 어른은 다 먹음"처럼 같이 간 사람의 반응이 글 곳곳에 들어가 진짜 후기처럼 읽힙니다.
- **편견을 먼저 꺼내고 뒤집습니다.** "이 음식은 보통 ○○ 때문에 꺼리는데, 여기선 △△해서 괜찮았다" 구조가 메뉴마다 들어갑니다.
- **실용 정보는 밑줄 + 굵게.** 위치(역 바로 앞), 주차(가게 뒤 넉넉함), 특산물 메뉴처럼 검색해서 들어온 사람이 찾는 정보만 강조합니다.
- **메뉴 이름은 굵게.** 처음 등장할 때 한 번만 굵게 표시합니다.
- **사장님 서비스 디테일.** 아이 몫은 순하게 따로 조리, 반찬 리필 등 직접 겪은 응대를 한 줄씩 넣습니다.
- **방문 시간 팁.** "브레이크타임 끝나자마자 갔다"처럼 내가 간 시간을 근거로 팁을 줍니다.
- **키워드 반복.** 가게 이름 4~5회, 지역명(시/읍 단위 2개)이 본문 곳곳에 자연스럽게 나옵니다.

### 아쉬운 점 (우리는 다르게 할 것)
- 주소·영업시간·가격을 한눈에 볼 요약이 없어서, 정보를 찾는 사람이 끝까지 스크롤해야 합니다. → **"한눈에 보기" 요약을 위에 넣습니다.**
- 아쉬운 점이 거의 없어 광고처럼 보일 수 있습니다. → **솔직한 총평에 아쉬운 점을 넣습니다.**
- 소제목이 3개뿐이라 메뉴 후기 구간이 깁니다. → **"메뉴와 가격"과 "직접 먹어본 후기"를 나눕니다.**
- 추천 대상이 없습니다. → **"이런 분께 추천해요"를 넣습니다.**

## 2. 내 블로그 맛집 글 구성 (이대로 씁니다)

```
제목: [지역] 맛집 [가게명], [대표 메뉴/특징] 후기   ← 30자 이내, 지역+맛집을 맨 앞에

(대표 사진 1장)
도입 2~3문단: 이 지역/메뉴 이야기 → 내가 가게 된 계기(누구와, 어떤 일정 중에)

## 한눈에 보기
가게 이름: / 위치: / 영업시간: / 주차: / 대표 메뉴: 가격   ← 메모에 있는 것만

---
## 찾아가는 길과 주차
(외관 사진 1~4장)
랜드마크 기준 위치 → 대중교통/자차 각각 → __주차 정보__ → 주변에 같이 들를 곳

---
## 매장 분위기
(내부 사진 1~2장)
분위기 한 줄 평 → 들어설 때 첫 느낌 → 좌석/손님층 → 내가 간 시간 기준 방문 팁

---
## 메뉴와 가격
(메뉴판 사진)
대표 메뉴 → 곁들임 메뉴 → 이 가게만의 특별 메뉴 강조 → 우리가 고른 조합과 이유

---
## 직접 먹어본 후기
(상차림 전체 사진) 상차림 구성 1문단
메뉴마다 반복:
  (그 메뉴 사진 1~2장)
  **메뉴명** 소개 → 맛/식감/양 → 동행자 반응 → 같이 먹으면 좋은 조합

---
## 솔직한 총평
좋았던 점 2~3가지 → 아쉬운 점 1~2가지(메모에 있을 때)
이런 분께 추천해요: 3줄
마무리 1~2문장

태그 12~15개
```

## 3. 문장·서식 규칙

| 항목 | 규칙 |
|---|---|
| 문단 | 1~3문장, 문단 사이 빈 줄 |
| 말투 | 친근한 '~요'체. 끝맺음을 섞기: ~했어요 / ~더라고요 / ~였어요 / ~좋겠어요 / 가끔 ~! |
| 굵게 `**` | 메뉴 이름 처음 나올 때, 핵심 결론 한 구절 |
| 밑줄 `__` | 위치·주차·영업시간·특별 메뉴 같은 실용 정보. 구간당 1~2개 |
| 사진 | 사진 묶음 → 설명 순서. 같은 장면 2장은 연달아 배치 |
| 동행자 | 같이 간 사람의 반응을 메뉴 후기마다 1번 이상 (메모에 있을 때) |
| 편견 뒤집기 | 호불호 있는 메뉴는 "보통 ○○라서 망설이는데 → 직접 먹어보니 △△" |
| 키워드 | 가게 이름 4~5회, 지역명 3~5회, 대표 메뉴명 3회 이상 자연스럽게 |
| 이모지 | 쓰지 않거나 글 전체에 1~2개 (`:)` 정도) |
| 금지 | 메모에 없는 가격·시간·위치 지어내기, 다른 블로그 문장 가져오기 |

---

## 4. 태그 공식 (12~15개)

| 유형 | 공식 | 예시 (가상의 가게) |
|---|---|---|
| 지역 맛집 | 시+맛집, 읍/동+맛집 | 춘천맛집, 소양동맛집 |
| 지역+음식 종류 | 지역+한식/중식/카페 | 춘천한식 |
| 가게 이름 | 가게명 그대로 | 소양닭갈비 |
| 랜드마크 맛집 | 역/시장/관광지+맛집 | 춘천역맛집, 소양강맛집 |
| 지역+메뉴 | 지역+대표메뉴 | 춘천닭갈비, 소양동막국수 |
| 메뉴 | 메뉴명, 메뉴+정식/세트 | 철판닭갈비, 막국수 |
| 여행 연계 | 지역+여행맛집, 지역+가볼만한곳 | 춘천여행맛집 |
| 상황 | 가족외식, 아이랑맛집 등 (메모에 맞을 때) | 아이랑맛집 |

## 5. 올리기 전 체크리스트

- [ ] 제목 맨 앞에 지역+맛집이 있다
- [ ] "한눈에 보기"의 정보가 모두 메모와 일치한다
- [ ] 모든 사진이 내가 찍은 사진이다
- [ ] 메뉴마다 사진 → 설명 순서이고, 내 느낌이 한 줄 이상 들어갔다
- [ ] 아쉬운 점 또는 추천 대상이 들어갔다
- [ ] 참고 글이 있다면 유사도 검사를 통과했다 (`check_similarity.py`)
- [ ] 소리 내어 읽었을 때 내 말투 같다
